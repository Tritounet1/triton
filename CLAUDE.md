# Instructions for Claude

## Code comments

Don't add any comments to code you write (no explanatory prose, no JSDoc,
no section headers). Exception: an `eslint-disable`/
`// eslint-disable-next-line` is still allowed when actually needed (it's
a functional directive, not an explanatory comment) - in that case, no
justification line above it, just the bare directive.

This only applies to code *you* write or modify. Don't strip comments
already present elsewhere in the repo.
